## 핵심 발견

1. **계산기류 경쟁 환경이 바뀌었다.** 챔피언스 출시 후 한국어 대전 도구가 여러 곳: OP.GG(능력 포인트·성격·데미지·티어·도감·팀빌더), GameWith 한국어판(육성 시뮬·내구 조정·스피드 비교·데미지·사용률 DB·게시판), pokical.com(쇼다운 기반 한국어 계산기). "한국어 도구 경쟁 거의 없음" 전제는 불성립.
2. **챔피언스에서 능력치 규칙이 바뀌었다.** 개체값 31 고정, 노력치 → 능력 포인트(총 66, 능력치당 최대 32). 실수치 계산기 입력 UI 설계가 달라지고, 개체값 판정 수요는 챔피언스 유저에게 사실상 없음.
3. **노출 대비 클릭 손실은 두 종류.** (a) 8~9위라 클릭 없음: 에스퍼 약점 8.7, 단칼빙 진화 레벨 9.1, 포챔스 순위 8.4, 기합구슬 8.6. (b) 4~6위인데도 클릭 없음: 땅타입 4.2/CTR 0.43%, 강철타입 5.4, 한카리아스 5.6 → SERP 구조(AI 요약, 위키·블로그 스니펫) 문제일 가능성(가정).
4. **절대 규모는 포켓몬 이름 검색에서 나온다.** 상세 기본 노출 1,185,628 = 전체의 약 48.5%. CTR을 1%p만 올려도(0.38→1.38%) 28일 약 11,900클릭 추가(단순 산술, 예측 아님). 신규 기능의 규모와 비교할 기준선.
5. **후보 4개의 외부 근거는 비대칭.** 실수치 계산기는 수요·경쟁 모두 확인. 성격표는 나무위키가 완비, 차별화 여지 작음. 파티 커버리지는 GameWith 유사 기능이 있다고 요약에 나오나 미확인. 즐겨찾기는 외부 근거 없음(내부 리텐션 판단 영역).

## 산업 트렌드

성장 동인:
- 챔피언스가 대전 진입 장벽을 낮춤(개체값 고정, 능력 포인트) → 도구형 쿼리 증가 가능.
- Z-A DLC(메가 루카리오 Z 등, 2025-12-10)가 "메가 ○○ Z" 쿼리 생성, 지금도 노출 2,201. 10세대 Winds/Waves는 2027 Switch 2, 시기 미정 → 이번 분기 과제 아님.
- 한국어 챔피언스 도구 생태계 형성 중(수요의 간접 증거이자 경쟁).

저해 요인:
- AI 요약의 클릭 잠식: Seer Interactive(정보성 쿼리 3,119개, 2024-06~2025-09) AI 요약 질의 유기 CTR 1.76%→0.61%, 요약 없는 질의도 2.72%→1.62%. 한국 적용 미검증. 정답이 짧은 질의일수록 대체 크다는 추정은 가정.
- 네이버 통합검색 구조(신뢰도 낮은 자료, 확인 필요). 네이버 유입은 세션 약 25,000(약 29%), 질의는 서치어드바이저에서만 확인 가능.
- 신뢰도 높은 위키·공식 사이트와 챔피언스 특화 도구 사이의 "범용 도감" 포지션.

## 노출 높고 클릭 없는 주제: 이길 수 있는 형태의 단서
1. 정답이 한 줄로 끝나는 질의(약점, 진화 레벨, 키·몸무게)는 위키·AI 요약이 대체하기 쉬움 → 순위 올려도 CTR 상승 제한 가능(가정). "비교·필터·조합" 질의에서는 도구형이 유리: 포켓몬 상성 2.9위 CTR 11.9%, 퀴즈 9.93%, 상성 계산기 56.9%.
2. 이로치는 이름+이로치 질의 1위권(마스카나 이로치 1.5위). 이미 이기는 형태.
3. 8~9위권 주제는 콘텐츠 보강·title 조정 효과가 클 수 있음. 상세 title에 키워드 없음 → SEO 설계(seo-specialist) 영역.
4. 챔피언스 티어·순위는 OP.GG·GameWith와 정면 경쟁. 데이터 우위는 판단 불가.

1. SERP 순위·검색량 미조회 → 경쟁 순위는 가정. 사용자 시크릿 모드 확인 권장: 에스퍼 약점 / 야돈 / 땅타입 / 모토마 진화 / 게을킹 종족값 / 메가루카리오z / 성격표 / 포켓몬 계산기. 네이버 검색광고 키워드 도구로 월간 검색량도.
2. 기합구슬은 기술 이름. 비구슬 미확인.
3. 챔피언스 능력치 공식(HP = 종족값 + 능력포인트 + 75, 기타 (종족값 + 능력포인트 + 20) × 성격보정)은 검색 요약 출처. 구현 전 OP.GG 결과와 대조 필요.
4. 챔피언스 모바일 출시일 출처 충돌.
5. AI 요약 CTR 영향은 영어권 연구.
6. 네이버 통합검색 개편 정보는 신뢰도 낮음.

1. competitor-map의 "한국어 도구 경쟁 거의 없음", "도구 검색은 블루오션" 전제 폐기·재평가.
2. 후보 1: 수요·경쟁 모두 확인. 단독 도구보다 상세·종족값 맥락 결합형이 강점(상세 PV 254,427, 종족값 질의 노출 13,095)과 연결. 능력 포인트 방식 기본 여부 설계 판단 필요.
3. 후보 2: 단독 가치 낮음, 후보 1의 부속. 25종 고정 데이터라 저비용.
4. 후보 3: 외부 근거 약함. 상성 랜딩(세션 12,837, 참여율 0.48) 이탈 감소 내부 목적에 맞음.
5. 후보 4: 외부 근거 없음. 재방문 비중(세션 약 절반)으로 내부 평가.
6. **저CTR은 신규 기능이 아니라 검색 결과 노출 방식 문제일 수 있음.** 상세 title/스니펫, 타입 페이지 FAQ 리치 결과 비적용 가능성 점검이 신규 기능 하나보다 효과 클 수 있음(상세 노출 1,185,628, CTR 1%p당 약 11,900클릭).
7. 세그먼트: 1차(대전)는 후보 1·3, 2차(일반)는 도감·진화·이로치 → SEO 개선에 가까움, 3차(검색 유입)는 8~9위권 질의 개선 = 6번.
8. 네이버 서치어드바이저 질의 데이터(세션 약 29%) 미포함 → 같은 표 작성 필요.
