# Next.js 설정 가이드

캐시 전략과 `next.config.js`의 의사결정을 규정한다.

관련 문서 — 라우트 경로 설계와 `_fetch`/`_metadata` 배치는 `structure.md`, 데이터 패칭과 서버·클라이언트 경계는 `coding.md`, 배포 전 검증은 `workflow.md`.

---

## 캐시 정책

두 개의 층이 함께 동작한다. **혼동하지 말 것** — `revalidate`는 서버가 페이지를 다시 만드는 주기이고, `Cache-Control`은 브라우저·CDN이 응답을 보관하는 기간이다.

### ISR (`revalidate`)

| 값               | 용도                                            |
| ---------------- | ----------------------------------------------- |
| `31536000` (1년) | 도감·기술·특성 상세 — 게임 데이터라 사실상 불변 |
| `86400` (1일)    | 챔피언스 등 주기적으로 갱신되는 메타 데이터     |

> **Why 1년인가:** 포켓몬 종족값·타입·기술 데이터는 게임 버전이 올라가지 않는 한 바뀌지 않는다. 무기한으로 두지 않는 이유는 백엔드 데이터 정정이 반영될 통로를 남기기 위해서다.

### `Cache-Control` (`headers()`)

| 경로  | 값                              | 의미                                   |
| ----- | ------------------------------- | -------------------------------------- |
| `/`   | `max-age=0, s-maxage=86400`     | 브라우저는 매번 재검증, CDN은 1일 보관 |
| 그 외 | `max-age=10800, s-maxage=86400` | 브라우저 3시간, CDN 1일                |

> **Why 홈만 `max-age=0`인가:** 홈은 오늘의 포켓몬·퀴즈처럼 자주 바뀌는 콘텐츠를 담아, 브라우저가 3시간 묵은 화면을 보여주면 안 된다. CDN 캐시는 유지해 원본 부하는 막는다.

## `next.config.js` 의사결정

설정 전체를 나열하지 않는다 — 파일을 열면 보인다. 여기에는 **왜 그렇게 했는지**가 있는 항목만 둔다.

### `redirects()` — 레거시 쿼리 URL

구버전은 폼을 쿼리 파라미터(`?activeType=mega`)로 표현했다. Path 구조로 전환하면서 기존 URL을 301로 넘긴다.

> **Why 301인가:** 302(임시)로 두면 검색엔진이 기존 URL의 색인을 유지해 중복 콘텐츠가 된다. 영구 이전을 알려야 색인이 새 URL로 옮겨간다.

### `headers()` — 경로별 캐시

위 캐시 정책을 적용한다. 홈과 그 외를 나누는 이유는 앞 절 참조.

### `webpack()` — SVG 변환

`@svgr/webpack`으로 SVG를 React 컴포넌트로 불러온다. 아이콘에 `fill`·`width` 등을 props로 넘길 수 있고, 별도 HTTP 요청 없이 인라인된다.

### `compiler.removeConsole` — 프로덕션 한정

빌드 시 `console.*` 호출을 제거한다. 개발 중에는 남겨 디버깅에 쓴다.

## 빌드 주의사항

**개발 서버가 떠 있는 상태에서 `npm run build`를 실행하지 않는다.** `.next` 디렉토리를 공유하므로 실행 중인 서버가 죽는다.
