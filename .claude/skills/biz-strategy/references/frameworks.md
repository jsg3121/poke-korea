# 비즈니스 분석 프레임워크

에이전트가 분석 시 참조하는 프레임워크 가이드이다.

---

## 거시환경 분석: PESTLE

외부 환경 요인을 6가지 차원으로 분석한다.

| 요인 | 분석 대상 | 포케코리아 예시 |
|------|----------|----------------|
| **P**olitical (정치) | 규제, 정책, 무역 | 포켓몬 IP 저작권 정책(닌텐도/게임프리크), 광고 규제 |
| **E**conomic (경제) | 경기, 환율, 투자 | 온라인 광고 단가(AdSense RPM), 게임 소비 지출 트렌드 |
| **S**ocial (사회) | 인구, 문화, 트렌드 | 포켓몬 팬덤 규모, 신작 출시 화제성, 이로치/대전 문화 |
| **T**echnological (기술) | 기술 발전, 혁신 | 검색엔진 알고리즘 변화(구글/네이버), 모바일 웹 사용 증가 |
| **L**egal (법률) | 법규, 지적재산 | 포켓몬 이미지·명칭 사용 범위, 팬사이트 가이드라인 |
| **E**nvironmental (환경) | 환경 요인 | (해당 사항 적음) |

## 산업구조 분석: Porter's 5 Forces

산업의 경쟁 강도와 수익성을 5가지 힘으로 분석한다.

| 힘 | 질문 | 분석 포인트 |
|----|------|------------|
| 기존 경쟁자 | 현재 얼마나 많은 유사 서비스가 있는가? | 나무위키, 포켓몬 위키, PokemonDB/Serebii(해외), yakkun(일본) |
| 신규 진입자 | 새로운 경쟁자가 진입하기 쉬운가? | 정보 사이트 진입 장벽 낮음, 단 한국어 도구·데이터 구축은 진입 비용 |
| 대체재 | 다른 방법으로 같은 문제를 해결할 수 있는가? | 유튜브 공략 영상, 커뮤니티(디시/아카), 게임 내 도감 |
| 공급자 교섭력 | 핵심 리소스 공급자의 영향력은? | 데이터 소스(PokeAPI 등) 의존도, 광고 플랫폼(구글) 정책 |
| 구매자 교섭력 | 사용자의 전환 비용은 얼마나 낮은가? | 매우 낮음 (무료 서비스, 검색 한 번으로 경쟁 사이트 이동) |

## 내부 역량 분석: SWOT

| | 긍정적 | 부정적 |
|---|--------|--------|
| **내부** | Strengths (강점) | Weaknesses (약점) |
| **외부** | Opportunities (기회) | Threats (위협) |

### SWOT 작성 원칙
- 각 항목에 최소 3개, 최대 5개
- 항목마다 "왜 그런가?" 근거 1줄 필수
- SO/WO/ST/WT 전략 매트릭스 도출 권장

## 포지셔닝 분석: Value Proposition Canvas

| 고객 측 | 제품 측 |
|---------|---------|
| Customer Jobs (해결할 과제) | Products & Services |
| Pains (고통점) | Pain Relievers |
| Gains (기대 이득) | Gain Creators |

## 경쟁 우위 분석: Jobs-to-be-Done

사용자가 "고용(hire)"하는 이유를 기능적/감정적/사회적 차원으로 분석한다.

| 차원 | 질문 | 예시 |
|------|------|------|
| 기능적 | 어떤 작업을 완료하려 하는가? | 포켓몬 타입 상성·종족값·기술 정보를 빠르게 찾기 |
| 감정적 | 어떤 기분을 느끼고 싶은가? | 대전·육성에서 확신을 갖고 판단하기 |
| 사회적 | 어떻게 보이고 싶은가? | 정보에 밝은 트레이너, 대전을 잘하는 유저 |

## 시장 규모 추정: TAM/SAM/SOM

| 단계 | 정의 | 추정 방법 |
|------|------|----------|
| TAM (Total Addressable Market) | 전체 잠재 시장 | 전 세계 포켓몬 게임/콘텐츠 이용자 수 × 광고 노출 가치 |
| SAM (Serviceable Available Market) | 접근 가능 시장 | 한국어로 포켓몬 정보·도구를 검색하는 이용자 |
| SOM (Serviceable Obtainable Market) | 실제 획득 가능 시장 | SEO 검색 유입으로 확보 가능한 한국어권 트래픽 |
