# 1.62.5 릴리즈 전 QA 반영

> **작업 날짜**: 2026-11-03
> **브랜치**: `feature/1.62.5-qa-fix`

## 📋 작업 개요

**작업 유형**: 버그 수정 / 하네스 보완
**담당**: jsg3121, Claude

## 🎯 작업 목표

main 릴리즈 PR 전에 `feature/1.62.5` 전체(`origin/main...feature/1.62.5`, 변경 파일 94개)를 QA하고, 이번 버전이 만든 문제와 화면·동작 변화 없이 고칠 수 있는 결함을 처리한다.

<!-- truncate -->

## 📉 왜 필요했나

`qa-orchestrator`로 lint·코드 리뷰·접근성·SEO·E2E를 모두 실행했다. 판정은 "수정 필요"였지만 차단 6건은 모두 이번 버전 전부터 있던 접근성 결함이었고, 이번 변경이 만든 퇴행은 없었다. E2E는 흐름 23개 46회 실행 중 45회 통과, 1회 스킵이었다.

대신 이번 버전이 원인인 권장 항목과 하네스 문제가 나왔다.

- `npm run format:check`가 실패했다. 1.62.5에서 추가한 `bigquery.js`에 Prettier를 적용하지 않았다. lint-check는 `src/`만 검사해 이를 놓쳤다
- 네이버 애널리틱스 항목을 개인정보처리방침에서 지웠는데 "최종 수정일"이 그대로였다
- `IntentLink` 타입이 실제로는 전달하지 않는 `ref`를 받는 것처럼 보였고, prefetch 방식이 Next.js 기본값에 조용히 의존하고 있었다
- 통합 브랜치에서 QA를 돌리자 `block-version-root-edit.sh` 훅이 `e2e/` 쓰기를 막았고, 하위 검사가 spec을 다른 곳에 쓴 뒤 `cp`로 복사하는 우회를 했다

## ✨ 주요 변경사항

### 변경 1: `bigquery.js` 포맷 적용

Prettier를 적용해 `format:check` 실패를 해소했다.

### 변경 2: 개인정보처리방침 최종 수정일 갱신

처리방침 문구가 바뀐 날(네이버 애널리틱스 제거, 2026-11-03)로 "최종 수정일"을 고쳤다. 처리방침은 변경 사실을 공개해야 하는 문서다.

### 변경 3: 통합 브랜치에서 테스트 산출물 폴더 편집 허용

`block-version-root-edit.sh`가 `e2e/`·`test-results/`·`playwright-report/`를 예외로 통과시킨다. 셋 다 `.gitignore` 대상이라 커밋에 들어가지 않으므로 "통합 브랜치에는 머지 커밋만" 원칙을 깨지 않는다. 이름이 비슷한 다른 경로(`e2e-other/` 등)와 `src/`·`.claude/`는 그대로 막는다.

### 변경 4: 화면·동작을 바꾸지 않는 접근성 결함 2건

| 위치 | 문제 | 수정 |
| --- | --- | --- |
| `DetailFormRow` 이로치 토글 | `<a>`에 button 전용 `aria-pressed` (WCAG 4.1.2) | 형제 폼 링크와 같은 `aria-current` |
| `QuizResultPopup` 퀴즈 이동 링크 | `aria-label`("퀴즈 풀러 가기")이 보이는 텍스트(`{퀴즈명} 풀러 가기`)를 포함하지 않음 (WCAG 2.5.3) | `aria-label`을 지워 보이는 텍스트를 이름으로 사용 |

이로치 토글의 스타일은 `aria` 속성이 아니라 `active` 값으로 정해져 화면이 바뀌지 않는다.

### 변경 5: `IntentLink` 타입 정리와 prefetch 기본값 기록

- props 타입을 `ComponentPropsWithoutRef` 기반으로 바꾸고 `legacyBehavior`를 제외했다. React 18 함수 컴포넌트라 `ref`가 조용히 버려지고, `legacyBehavior`는 의도 핸들러를 자식에 전달하지 않는다. 동작 변화 없음
- `router.prefetch(href)`는 kind를 지정하지 않아 Next.js 15.5의 기존 구현에서 `FULL`로 동작한다. `loading.tsx`가 없어 `AUTO`로는 동적 경로를 거의 받지 못하므로 목적(보이기만 한 링크의 RSC prefetch를 끄고, 누르려 할 때 받기)에 맞다. 다만 segment cache가 켜지면 기본값이 `AUTO`로 바뀌므로 업그레이드 때 다시 확인하도록 ADR-0025 "결과"에 기록했다. `PrefetchKind`는 공개 API가 아니라 코드에 명시하지 않았다

## ⚠️ 구현 시 고려한 점

### 처리하지 않은 접근성 차단 4건

화면이나 동작이 바뀌는 항목은 이번 릴리즈에서 고치지 않았다.

| 항목 | 넘긴 이유 |
| --- | --- |
| 전역 `:focus { outline-none }`로 포커스 표시 없음 (2.4.7) | `:focus-visible`로 좁히면 텍스트 입력은 마우스 클릭에도 테두리가 보여 화면이 바뀐다 |
| 비활성 버전 링크 대비 3.0:1 (1.4.3) | 색을 바꿔야 한다 |
| 404 포켓몬 칩 대비 4.35:1 (1.4.3) | 색 토큰을 바꿔야 한다. `text-primary-2` 대비 문제와 같은 원인(토큰 단위, ADR 후보) |
| 퀴즈 결과 팝업 포커스 이동·가두기·Esc 닫기 없음 (2.4.3, 2.1.1) | 키보드 동작이 새로 생긴다 |

QA의 접근성 권장 항목(메뉴 `aria-current`, 챔피언스 하위 메뉴 hover 전용, 외부 링크 새 창 안내 등)과 SEO 기존 결함 3건도 이번 범위 밖이다.

## 🔍 검증

- `tsc --noEmit`, 변경 파일 `eslint`·`prettier --check`, `npm run format:check` 통과
- 훅: 통합 브랜치에서 `e2e/`·`test-results/`·`playwright-report/`는 통과, `src/`·`.claude/`·`e2e-other/`는 차단, 서브 브랜치는 기존대로 통과
- `bigquery.js` 포맷 적용 후 dry run 정상
- **확인하지 않은 것**: 수정 후 QA·E2E를 다시 돌리지 않았다. 접근성 2건은 속성만 바뀌어 스크린리더로 직접 확인하지 않았다

## 📌 후속 관찰 대상

- 배포 후 CLS 재측정 — 폰트 preload 제거로 `/quiz` 0.113, `/ability/9` 0.109 등 배포 전 값이 이미 0.1 언저리다
- 운영 Network 탭에서 의도 기반 prefetch 확인 — 개발 모드에서는 `router.prefetch`가 동작하지 않는다
