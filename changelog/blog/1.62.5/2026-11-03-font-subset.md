# 서브셋 폰트를 상용 한글 2,350자로 다시 줄여 600KB → 200KB

> **작업 날짜**: 2026-11-03
> **브랜치**: `feature/1.62.5-font-subset`

## 📋 작업 개요

**작업 유형**: 성능 개선
**담당**: jsg3121, Claude

## 🎯 작업 목표

모든 페이지가 내려받는 Gmarket Sans 서브셋 폰트 두 개(Medium·Bold)의 용량을 줄여, LCP 이미지와 다투는 다운로드 부담을 덜어낸다.

<!-- truncate -->

## 📉 왜 필요했나

Lighthouse 모바일 측정에서 페이지 전체 전송량 약 1,450KB 중 **폰트가 약 600KB(약 40%)**였다. 두 폰트는 굵기마다 약 300KB였다.

1.28.0(2026-01-02) 폰트 서브셋 작업은 "한글 2,350자"로 줄였다고 기록했지만, 실제로 지정한 범위는 `U+AC00-D7A3`이었다. 이 범위는 **한글 음절 11,172자 전체**다. 폰트 파일을 열어 확인해도 두 굵기 모두 한글 11,172자가 들어 있었다.

사이트에서 실제로 쓰는 한글을 세어 보니 다음과 같았다.

| 대상                                                      | 한글 음절 |
| --------------------------------------------------------- | --------- |
| 프론트 코드(`src/`)                                       | 686자     |
| 프론트 코드 + 백엔드 데이터(`pokemon-server`의 json·db-backup) | 1,113자   |
| 그중 상용 한글 2,350자(KS X 1001) 밖의 글자               | **0자**   |

## ✨ 주요 변경사항

### 변경 1: 상용 한글 2,350자 + 기존 영문·숫자·기호로 다시 서브셋

`public/fonts/GmarketSansMedium.subset.woff2`, `GmarketSansBold.subset.woff2`를 교체했다. 파일 이름은 그대로라 `globals.css`의 `@font-face`는 바꾸지 않았다.

| 굵기   | 변경 전 (한글 11,172자) | 변경 후 (한글 2,350자) | 감소 |
| ------ | ----------------------- | ---------------------- | ---- |
| Medium | 299KB                   | 105KB                  | -65% |
| Bold   | 301KB                   | 97KB                   | -68% |
| 합계   | 600KB                   | 202KB                  | -66% |

- 한글이 아닌 문자 84개(영문·숫자·기호)는 기존과 같게 유지했다.
- 위에서 센 사용 글자 1,113자가 모두 들어 있는지 새 폰트의 글자표(cmap)로 확인했다.

### 재생성 방법

```bash
# 상용 한글 2,350자 목록 (EUC-KR 완성형 0xB0A1–0xC8FE)
python3 -c "print(''.join(bytes([a,b]).decode('euc-kr') for a in range(0xB0,0xC9) for b in range(0xA1,0xFF)))" > ks2350.txt

pyftsubset GmarketSansMedium.woff2 --text-file=ks2350.txt --unicodes="U+0020-007E" \
  --flavor=woff2 --layout-features='*' --output-file=GmarketSansMedium.subset.woff2
```

Bold도 같은 명령으로 만든다. 원본이 없으면 기존 서브셋 파일을 입력으로 써도 결과가 같다. 기존 서브셋에 2,350자가 모두 들어 있기 때문이다.

## 🔍 검증

- 새 폰트 두 개의 한글 글자 수(2,350자), 한글 외 문자 수(84개)를 `fontTools`로 확인
- 사이트 사용 글자 1,113자 중 누락 0자 확인
- 배포 후 확인 필요: 상세·기술·특성 페이지 본문이 Gmarket Sans로 보이는지

## 📌 참고 사항

- 2,350자 밖의 희귀 음절이 나중에 데이터에 들어오면, 그 글자만 대체 폰트(`system-ui`)로 표시된다. 화면이 깨지지는 않는다.
- 폰트는 CloudFront에서 1년, 브라우저에서 1일 캐시된다. 배포 스크립트(`deploy.sh`)가 `/*`를 무효화하므로 CloudFront는 바로 새 파일을 준다. 브라우저에 남은 예전 폰트(상위 집합)는 최대 1일 쓰이고 문제는 없다.
- 1.28.0 changelog의 "2,350자" 서술은 당시 기록이라 고치지 않고 이 글에서 정정한다.
- 페이지별 Lighthouse 변화는 1.62.5 성능 측정 글에서 비교한다.
