# 1.54.0 — 모바일 개편 기획서 반응형 기준 개정

> **작업 일자**: 2026-06-16
> **작업 브랜치**: `feature/1.54.0-plan-responsive-revision`

## 📋 작업 개요

**작업 유형**: 기획서 개정 (반응형 전환 반영)
**담당**: jsg3121 + Claude

[ADR-0007](/blog/1-54-0-responsive-pivot)에서 반응형으로 전환을 결정한 뒤,
적응형 전제로 작성됐던 모바일 개편 기획서를 반응형 기준으로 개정했다.
설계도가 옛 방향(적응형)이면 코드 작업 시 혼란이 생기므로, 코드 작업 전에 정리했다.

## 🔧 개정 내용

| 섹션 | 변경 |
| --- | --- |
| §3.3 스트랭글러 근거 | "모바일 뷰만 교체" → "라우트별 반응형 단일 뷰로 교체" |
| §3.4 범위 | "모바일 우선·데스크톱 현행 유지" → "반응형 단일 컴포넌트로 모바일·데스크톱 함께" |
| §4.1 렌더링 전략 | 적응형 항목(UA 분기, getIsMobile, 결정 트리, min-width) 제거 → 반응형 브레이크포인트 규칙·반응형 그리드로 교체. 완료된 토큰 항목은 체크 처리 |
| §5 작업 사이클 | "모바일 뷰 구현" → "반응형 단일 뷰 구현(분리 뷰 통합)" |
| §6 리스크표 | "`md:` 0건 검증"(적응형) → 반응형 회귀·공존 리스크로 교체 |
| 상단 배너 | "후속 개정 예정" → "§3~§5 개정 완료" |

## 📌 유지한 부분

- **§2 현황 분석**: 개편 *이전* 상태를 기술하므로 적응형 구조 설명을 그대로 둠 (사실 기록)
- 완료된 토큰·DS Foundations 항목: 반응형에서도 유효

## ⏭️ 다음 작업

- 기존 UA 분기/`useDevice`를 스트랭글러로 점진 제거
