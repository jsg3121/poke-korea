# 포켓몬 상세 — 타입 상성 배율 표기 개선

> **작업 날짜**: 2026-08-09
> **브랜치**: `feature/1.55.0-evolution`

## 📋 작업 개요

**작업 유형**: 디자인 변경 / UX 개선
**담당**: jsg3121, claude

## 🎯 작업 목표

상세 페이지의 타입 상성 섹션에서 배율(×4, ×2 등)이 타입 태그와 **같은 크기·형태의 배지**로 표시돼, 배율인지 타입인지 한눈에 구분되지 않았다. 배지가 두 종류 정보에 동시에 쓰여 혼동을 유발했다.

이미 타입 상성 계산기에서는 "배지=타입" 단일 규칙(배율은 텍스트)으로 이 문제를 해결한 이력이 있어, 상세 페이지도 동일한 디자인 언어로 통일한다.

<!-- truncate -->

## 🎨 디자인 변경

### 배율 표기: 배지 → 문장 + 좌측 색 보더

- 배율을 배지 대신 **"받는 데미지 4배"** 문장(방어 관점 유지)으로 표기하고, 행 좌측에 위험도별 색 보더를 둔다.
- 타입만 배지(Tag)로 남겨 "배지=타입" 단일 규칙을 만든다.

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 배율 | `×4` 배지(타입과 동일 크기) | "받는 데미지 4배" 문장 + 좌측 색 보더 |
| 타입 | 배지 | 배지 (유지) |

### 문장 색상: 대비 확보

배율 문장 색은 위험도 grade 색이 아니라 진한 기본색(primary-1)을 쓴다. 상세 카드 배경이 밝은 색이라 grade 색(어두운 계산기 배경 기준으로 제작)은 대비가 1.1~2.4로 WCAG 1.4.3(3:1)에 미달했다. 진한 기본색은 대비 9.66(AAA)을 확보하고, 위험도 색 신호는 좌측 보더가 담당한다.
