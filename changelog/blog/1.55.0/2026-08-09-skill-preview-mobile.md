# 포켓몬 상세 — 모바일 습득 기술 미리보기 5개로 축소

> **작업 날짜**: 2026-08-09
> **브랜치**: `feature/1.55.0-skill-preview`

## 📋 작업 개요

**작업 유형**: UX 개선
**담당**: jsg3121, claude

## 🎯 작업 목표

포켓몬 상세 페이지의 습득 기술(레벨업·머신) 미리보기가 모바일에서도 10개씩 노출돼, 좁은 세로 폭에서 표가 화면을 과도하게 차지했다. 모바일 미리보기를 5개로 줄인다. 전체 목록은 기존 "전체 보기" 링크로 유도되므로 정보 손실은 없다.

<!-- truncate -->

## 🎨 변경 사항

- 습득 기술 미리보기 개수를 **모바일 5 / 데스크톱 10**으로 분기한다(레벨업·머신 둘 다).
- 데이터 슬라이스라 CSS로 줄일 수 없어, 서버 주입 `isMobile`(`useDevice`)로 분기한다. 광고 슬롯과 동일한 패턴이라 하이드레이션 불일치가 없다.

## 🔧 기술적 세부사항

| 파일 | 내용 |
| --- | --- |
| `src/container/detail/DetailSkills.container.tsx` | 미리보기 개수를 모바일 5 / 데스크톱 10으로 분기 |

## 📌 참고 사항

- `DeviceProvider`가 루트 레이아웃 전체를 감싸므로 상세 페이지에서 `useDevice`가 정상 동작한다.
- 데스크톱 노출(10개)은 변경 없다.
