# 악 타입 설명의 "유일한 조합" 오류 수정

> **작업 날짜**: 2026-09-20
> **브랜치**: `feature/1.60.1`

## 📋 작업 개요

**작업 유형**: 버그 수정 (콘텐츠 사실 오류)
**담당**: jsg3121, claude

## 🎯 작업 목표

타입 상성 상세 페이지의 악 타입 설명에 **사실과 다른 단정 표현 2개**가 있었다. 두 문장 모두 특정 타입 조합을 "유일한 조합"이라 서술했지만, 실제로는 같은 특성을 가진 조합이 여럿 존재한다.

<!-- truncate -->

## 📉 무엇이 틀렸나

### 1. 악/고스트 — "무효가 3개인 유일한 조합"

고스트 타입이 이미 노말·격투 2개를 무효화하므로, **무효를 가진 타입 아무거나** 고스트와 조합하면 무효가 3개가 된다. 악/고스트만의 특성이 아니다.

| 조합 | 무효 3종 | 실존 포켓몬 |
| --- | --- | --- |
| 고스트/악 | 노말·격투·에스퍼 | 깜까미, 화강돌 |
| 고스트/강철 | 노말·격투·독 | 킬가르도, 타부자고 |
| 고스트/페어리 | 노말·격투·드래곤 | 따라큐, 날개치는머리 |
| 고스트/땅 | 노말·격투·전기 | 골루그, 데스판 |
| 고스트/비행 | 노말·격투·땅 | 흔들풍손, 둥실라이드 |

같은 파일의 강철 타입 설명이 이미 고스트/강철을 "무효가 3개"라고 서술하고 있어, **문서 내 자기모순** 상태이기도 했다.

### 2. 악/드래곤 — "둘 다 페어리에 약한 유일한 조합"

페어리에 2배를 받는 타입은 격투·드래곤·악 **3개**다. 그중 둘을 고르는 조합은 3가지이고, 셋 다 실존한다.

| 조합 | 실존 포켓몬 |
| --- | --- |
| 악/드래곤 | 모노두, 디헤드, 삼삼드래, 악식킹, 고동치는달 |
| 악/격투 | 곤율랭, 곤율거니, 부란다, 우라오스 |
| 드래곤/격투 | 짜랑고우, 짜랑고우거, 코라이돈 |

우라오스와 코라이돈은 대전에서 자주 쓰이는 포켓몬이라, 이용자가 오류를 발견하기 쉬운 문장이었다.

## ✨ 주요 변경사항

### 악/고스트 설명

```ts
// Before
'노말·격투·에스퍼를 전부 무효화해요. 무효가 3개인 유일한 조합이고, 약점은 페어리 하나뿐이에요.'

// After
'노말·격투·에스퍼를 전부 무효화해요. 무효가 3개이고, 약점은 페어리 하나뿐이에요.'
```

"약점은 페어리 하나뿐"은 계산 결과 정확해 그대로 두었다.

### 악/드래곤 설명

```ts
// Before
'페어리에 4배를 받아요. 악과 드래곤이 둘 다 페어리에 약한 유일한 조합이에요.'

// After
'페어리에 4배를 받아요. 악과 드래곤이 둘 다 페어리에 약하기 때문이에요.'
```

단정을 빼는 대신 **"왜 4배인가"를 설명하는 문장**으로 바꿔, 틀린 주장을 제거하면서 정보량은 유지했다.

## 🔍 검증 방법

이번 수정은 세 단계로 교차 검증했다.

1. **상성표 전수 계산** — `typeEffectivenessChart.ts`를 파싱해 18×18 매트릭스에서 악·에스퍼의 공격 행·방어 열 36칸과 조합별 배율을 계산
2. **DB 대조** — 반례 조합에 실제 포켓몬이 존재하는지 확인. 타입 조합이 이론상 가능해도 실존 포켓몬이 없으면 반례가 되지 못하므로, 이 단계가 필수였다
3. **외부 레퍼런스 확인** — PokemonDB·Smogon으로 코라이돈의 페어리 4배, 킬가르도·따라큐의 무효 3개를 재확인

검증 과정에서 **상성 수치 36칸, 예시 포켓몬 13종, 조합별 배율은 모두 정확**한 것으로 확인됐다. "에스퍼 공격을 무효화하는 유일한 타입은 악"이라는 다른 단정 표현도 전수 계산 결과 참이었다.

## 🔧 기술적 세부사항

**수정 파일**: `src/constants/typeDetailContent.ts` (문자열 2개)

타입·로직·렌더링 구조 변경은 없다. 상수 문자열만 바뀌므로 `typeEffectivenessChart.ts`, `typeShowcasePokemon.ts`를 포함한 다른 파일은 손대지 않았다.

## 📌 참고 사항

- 에스퍼 타입 설명 전체는 오류가 없어 수정 대상에서 제외했다.
- 악 타입 FAQ의 "약점 3개는 모든 타입 중에서도 적은 편"은 약점 3개가 18타입 중 8개가 해당하는 중앙값이라 표현이 느슨하지만, 틀린 서술은 아니라 이번 수정에 포함하지 않았다.
- 콘텐츠 서술을 추가할 때는 **"유일한", "가장" 같은 단정 표현을 쓰기 전에 전수 계산과 DB 대조**를 거치는 것이 안전하다. 이번 두 문장 모두 계산 한 번으로 반증되는 수준이었다.
