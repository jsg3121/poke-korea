# 기술 표 습득 열 너비 조정 — 기술 가르침 라벨 줄바꿈 수정

> **작업 날짜**: 2026-08-15
> **브랜치**: `feature/1.56.0-skills-expansion`

## 📋 작업 개요

**작업 유형**: 버그 수정 / 스타일 조정
**담당**: jsg3121, claude

## 🎯 작업 목표

데스크톱에서 기술 가르침 탭을 보면 습득 열의 `기술 가르침` 라벨이 두 줄로 쪼개져 행 높이가 들쭉날쭉해진다. 습득법 확장으로 조건 라벨이 길어지면서 드러난 문제다.

<!-- truncate -->

## ✨ 주요 변경사항

### 변경 1: 습득 열 너비 확대

조건 라벨은 습득법마다 길이가 크게 다르다. 실제 데이터를 조사한 결과다.

| 습득법 | 최장 라벨 | 길이 |
| --- | --- | ---: |
| 레벨업 | `Lv.32` | 5자 |
| 기술머신 | `TM175` | 5자 |
| 알 기술 | `알 기술` | 4자 |
| **기술 가르침** | **`기술 가르침`** | **6자** |

기존 `desktop:w-14`(56px)는 `Lv.12`·`TM24` 기준으로 잡힌 값이라, 한글 6자인 `기술 가르침`이 들어가지 못했다. 한글은 영문보다 글자 폭이 넓어 체감 초과폭이 더 크다.

```diff
- condition: 'desktop:w-14',   // 56px
+ condition: 'desktop:w-20',   // 80px = 한글 5자 + px-2 좌우 패딩(16px)
```

기술명 셀은 `flex-1`이라 남는 폭을 가져가므로, **습득 열을 넓히면 기술명이 그만큼 자동으로 줄어든다.** 별도 조정이 필요 없다.

### 변경 2: 줄바꿈 방지

폭을 넓혀도 앞으로 더 긴 라벨이 들어오면 같은 문제가 재발한다. 조건 셀에 `whitespace-nowrap`을 적용했다.

> **Why 줄바꿈 대신 넘침인가:** 라벨이 두 줄이 되면 그 행만 높아져 표 전체 리듬이 깨진다. 가로로 살짝 넘치는 편이 시각적 피해가 작다.

### 변경 3: Storybook 회귀 케이스 추가

이 문제가 다시 생기면 실제 페이지보다 story에서 먼저 드러나도록 케이스를 추가했다.

- `Tutor` — 조건 라벨이 가장 긴 케이스(회귀 확인용)
- `Egg` — 알 기술 라벨 케이스

기존 `Machine` story의 조건 라벨도 실제와 맞게 고쳤다. 습득 기술 통합 작업에서 `머신` 고정 문자열이 기술머신 번호(`TM24`)로 바뀌었는데 story가 따라가지 못한 상태였다.

## 📊 변경 요약

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 습득 열 너비 | `w-14` (56px) | `w-20` (80px) |
| 긴 라벨 처리 | 줄바꿈 | `whitespace-nowrap` |
| Storybook 케이스 | 레벨업 · 머신 | + 기술 가르침 · 알 기술 |
| `Machine` story 라벨 | `머신` | `TM24` (실제와 일치) |

| 사용처 | 조건 라벨 | 영향 |

| `DetailSkills` | `진화` · `최초` · `Lv.12` · `머신` | 짧은 라벨이라 무영향 |
