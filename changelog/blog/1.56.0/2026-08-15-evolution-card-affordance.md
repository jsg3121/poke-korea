# 진화 카드 링크 어포던스 개선 — 클릭 가능함을 시각적으로 전달

> **작업 날짜**: 2026-08-15
> **브랜치**: `feature/1.56.0-skills-expansion`

## 📋 작업 개요

**작업 유형**: UX 개선
**담당**: jsg3121, claude

## 🎯 작업 목표

진화 정보 카드의 링크 영역을 포켓몬 이미지에서 헤더 전체(이미지 + 도감번호 + 이름 + 트리거 배지)로 넓혔으나, **클릭할 수 있다는 신호는 그대로였다.** 영역만 넓히면 사용자가 인지하지 못하거나, 우연히 눌렀을 때 "왜 이동하지?"가 된다.

<!-- truncate -->

## ✨ 주요 변경사항

### 문제: 클릭 영역과 피드백 영역의 불일치

호버 효과(`hover:scale-105`)가 이미지 `div`에만 걸려 있었다.

```text
┌──────────────────────────────┐
│ ┌───┐  No.006                │
│ │ 🔥│  리자몽                 │  ← 링크 영역이지만 호버해도 무반응
│ └───┘  [레벨업]               │
└─┬────────────────────────────┘
  └ 여기 호버할 때만 이미지가 커짐
```

이름 위에 마우스를 올려도 아무 반응이 없어, **클릭 영역이 넓어진 것을 알 수 없었다.** 카드가 `border` 박스라 정적인 정보 카드로 보이는 것도 원인이다.

### 변경 1: 평상시에도 보이는 화살표

호버는 마우스를 올려야 알 수 있어, 올려보기 전까지는 링크인지 모른다. 화살표(`›`)를 상시 노출해 **호버 전에도** 이동 가능함을 알린다.

```text
┌──────────────────────────────┐
│ ┌───┐  No.006                │
│ │ 🔥│  리자몽             ›  │  ← 상시 표시
│ └───┘  [레벨업]               │
└──────────────────────────────┘
```

장식 요소이므로 `aria-hidden`이다 — 링크 목적은 `Link`의 `aria-label`이 이미 전달한다.

### 변경 2: 호버 피드백을 링크 전체로

`group` / `group-hover` 패턴으로 링크 어디에 마우스를 올려도 네 요소가 함께 반응한다.

| 요소 | 호버 시 |
| --- | --- |
| 링크 배경 | `hover:bg-primary-1/5` 연한 하이라이트 |
| 이름 | 밑줄이 투명 → 현재 색으로 |
| 화살표 | 오른쪽으로 이동 + 색 강조 |
| 이미지 | 확대 (기존 동작 유지) |

프로젝트에 이미 쓰이는 패턴을 조합했다 — `ChampionsQuickLinks`의 화살표 `group-hover:translate-x-1`, `MoveTable`의 행 배경 `hover:bg-primary-1/5`.

### 변경 3: 포커스 링을 링크로 이동

`focus-visible` 아웃라인이 이미지 `div`에 있어 키보드 포커스 시 이미지만 테두리가 생겼다. 실제 포커스 대상은 `Link`이므로 링크 전체를 감싸도록 옮겼다.

## 📊 변경 요약

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 링크 신호(평상시) | 없음 | 화살표 `›` |
| 호버 반응 범위 | 이미지만 | 링크 전체 (배경·이름·화살표·이미지) |
| 포커스 링 | 이미지 `div` | `Link` 전체 |

## 🔧 기술적 세부사항

**수정 파일**

- `src/container/detail/components/EvolutionConditionCard.component.tsx`

**여백 처리**

배경 하이라이트가 텍스트에 너무 붙지 않도록 `-m-1 p-1`을 썼다. 패딩으로 안쪽 여백을 주고 음수 마진으로 상쇄해, **카드 레이아웃은 그대로 두면서 하이라이트 영역만 넓힌다.**

**모션 감소 대응을 넣지 않은 이유**

프로젝트에 `prefers-reduced-motion` 대응 사례가 있으나(`StatBar`·`ChampionsMetaList`), 그것은 **자동 재생되는** 애니메이션이다. 이번 transform은 사용자가 마우스를 올렸을 때만 발생하는 짧은 반응이라 통상 접근성 문제로 다루지 않는다.
