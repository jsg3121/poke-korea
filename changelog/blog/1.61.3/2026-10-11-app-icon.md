# 홈 화면에 추가했을 때 로고 아이콘이 표시되도록 개선

> **작업 날짜**: 2026-10-11
> **브랜치**: `feature/1.61.3-app-icon`

## 📋 작업 개요

**작업 유형**: 기능 개선 / UX
**담당**: Claude Code

## 🎯 작업 목표

아이폰·안드로이드에서 사이트를 홈 화면에 추가하면 로고 아이콘이 보이게 한다. 홈 화면에서 열어도 주소창은 유지한다.

<!-- truncate -->

## 📉 왜 필요했나

사용자 제보: 아이폰에서 홈 화면에 추가해 앱처럼 쓰려고 했는데 아이콘이 **"포" 한 글자**로만 나온다.

홈 화면용 아이콘이 하나도 없었다. 루트 레이아웃에는 `favicon.ico`(16·32px)만 있었고 `apple-touch-icon`과 웹 앱 매니페스트가 없었다. iOS Safari는 `apple-touch-icon`이 없으면 페이지 제목("**포**케 코리아")의 첫 글자로 아이콘을 만든다.

## ✨ 주요 변경사항

### 아이콘 이미지 추가 (`public/assets/icons/`)

| 파일                        | 크기    | 용도                     |
| --------------------------- | ------- | ------------------------ |
| `app-icon-apple-180.png`    | 180×180 | iOS 홈 화면              |
| `app-icon-192.png`          | 192×192 | 안드로이드 매니페스트    |
| `app-icon-512.png`          | 512×512 | 안드로이드 매니페스트    |
| `app-icon-maskable-512.png` | 512×512 | 안드로이드 마스크 대응   |

- 로고(`logo.svg`)의 글자를 "POKE / KOREA" 2줄로 나누고 몬스터볼을 1.9배로 키웠다. 배경은 테마 색 `#27374D`다.
- 글자는 잘라내지 않고 로고 패스를 글자 단위 서브패스로 나눠 다시 배치했다. 그래서 원본 글꼴 모양이 그대로 유지된다.
- iOS가 투명 영역을 검게 채우므로 모두 불투명 PNG로 만들었다.
- maskable 아이콘은 로고를 지름 80% 안전 영역 안에 두었다.

### iOS: `metadata.icons.apple` 추가

```ts
// src/app/layout.tsx
icons: {
  icon: '/favicon.ico',
  apple: '/assets/icons/app-icon-apple-180.png',
},
```

### 안드로이드: `src/app/manifest.ts` 추가

`/manifest.webmanifest`가 생성된다. 아이콘 3종, `theme_color`, `display: 'browser'`를 지정했다.

## 🔍 검증

- `tsc --noEmit`, ESLint, Prettier 통과
- `npm run build` 통과. `/manifest.webmanifest`가 정적 라우트로 생성되고 내용이 의도대로인 것 확인
- 개발 서버에서 `/`·`/detail/25`·`/moves`를 iPhone UA로 요청했다. 세 페이지 모두 `<head>` 안에 `apple-touch-icon`·`manifest`·`icon` 링크가 들어 있다
- `/manifest.webmanifest`(`application/manifest+json`)와 아이콘 PNG 4장, `/favicon.ico` 모두 200 응답
- **아직 확인하지 않은 것**: 실기기에서 홈 화면에 추가했을 때 표시되는 모습

## ⚠️ 구현 시 고려한 점

자세한 근거는 ADR-0021에 남겼다.

- **파일 규칙(`src/app/apple-icon.png`)은 실측 후 기각했다.**
  - Next.js 15.5.18은 `metadata.icons` 설정이 있으면 파일 기반 아이콘을 무시한다.
  - 설정을 지우려면 favicon도 `src/app/`으로 옮겨야 한다. 그러면 Next.js가 favicon 캐시를 `max-age=0, must-revalidate`로 고정해 기존 캐싱 정책(브라우저 1일 / CloudFront 1년)과 충돌한다.
- **주소창 유지를 위해 `display: 'browser'`로 했다.**
  - iOS 26부터는 홈 화면에 추가한 사이트가 기본으로 주소창 없는 웹 앱으로 열린다. 사이트 쪽에서는 이를 통제할 수 없다.
  - 대신 화면 가장자리 스와이프로 뒤로 갈 수 있어 이 제약은 허용했다.

## 📌 참고 사항

- `/assets/*.png`는 1년 `immutable`로 캐시된다. **아이콘을 바꿀 때는 파일명을 바꿔야** 기존 방문자에게 반영된다.
